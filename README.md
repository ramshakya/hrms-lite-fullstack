# HRMS Lite - Full Stack Human Resource Management System

HRMS Lite is a lightweight Human Resource Management System built to demonstrate full-stack development skills including frontend, backend, REST APIs, database modeling, validations, and error handling.

---

## 🚀 Tech Stack

### Backend
- Python
- Django
- Django REST Framework
- SQLite (default, can switch to PostgreSQL)

### Frontend
- React (Vite)
- Axios / Fetch API
- Basic CSS

---

## 📦 Features

### 👨‍💼 Employee Management
- Create Employee
- Update Employee
- Delete Employee
- List Employees
- Unique Employee ID support

### 🕒 Attendance Management
- Mark Attendance (Present/Absent)
- View Attendance Records
- Link attendance with employee

### 🏢 Department Support
- Employee department tracking

### 🔐 Validations
- Unique employee ID
- Required fields validation
- Proper error handling
